# NEXUS AI – aplikacija (APK)

Samostalna Android aplikacija: NEXUS radi bilo gdje preko mobilnih podataka, bez računala.
Prepoznavanje govora i čitanje naglas idu preko telefona, a ima i widget „Pitaj NEXUS” (jedan dodir → odmah sluša).

APK se gradi automatski (GitHub Actions) i nalazi se u Releases pod oznakom `nexus-app`.
